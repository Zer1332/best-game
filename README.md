VOIDBLOOM — a 2D arena survivor. You are a lone wisp in a dark garden: drift with WASD or the arrow keys, aim with the mouse, hold click or SPACE to fire. Void creatures close in wave after wave; dissolve them, gather the bloom-shards they drop, level up and pick one of three blooms (damage, fire rate, multishot, magnet, and more). Every fifth wave wakes the Voidmother. Survive as long as you can — the garden keeps score.

All art is drawn procedurally on canvas and all sound is synthesized with WebAudio. No libraries, no network requests, no files beyond this repository.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
